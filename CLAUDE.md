# Claude Code instructions

Read `AGENTS.md` in this repository first — it contains the setup commands, architecture map, coding rules and gotchas for this project.

Also read the relevant guide in `node_modules/next/dist/docs/` before writing code: this Next.js 16 setup has breaking changes and APIs that differ from older versions.

Quick commands:

```bash
npm install        # postinstall generates the Prisma client
npm run dev        # http://localhost:3000 (admin: /admin)
npm run typecheck
npm run lint
npm run build
```

Docs: `docs/ARCHITECTURE.md`, `docs/DATA-BACKUP.md`.
